# 火龙探险测试清单

[返回项目首页](../README.md)

此文件是每次发布前应执行的回归清单，不代表下列项目已全部自动通过。

## 静态检查

```bash
node tools/check-site.mjs
node tools/test-boot.mjs
node --check web/boot.js
node tools/serve.mjs 8080
```

检查工具验证构建路径、页面必需元素、CSS资源和文档中的本地文件链接。它不替代Unity编译、图形渲染或完整通关测试。

## 浏览器加载

- [ ] 页面标题只显示“火龙探险”，无旧的“Unity WebGL Player”前缀。
- [ ] 配置、loader、data、framework、wasm和样式请求成功。
- [ ] 加载进度结束后能看到主菜单，控制台无阻断性异常。
- [ ] 第一次点击后声音正常，静音按钮能切换。
- [ ] 窗口缩放后画面保持可操作；不将触屏完整兼容视为已验收。
- [ ] 阻断配置或loader请求时显示错误，加载条不无限停留。

## 核心流程

- [ ] 左右移动和朝向一致，镜头只横向跟随。
- [ ] 原地跳、移动中跳、落地后继续移动，动画无永久卡住。
- [ ] J与鼠标左键均能发射火球；连续输入受冷却控制。
- [ ] 近距离、远距离、低帧率和薄碰撞体下检查火球命中。
- [ ] 同一敌人不重复死亡加分；击杀默认加20分。
- [ ] 金币计分、金币消失和音效对应。
- [ ] 普通敌人伤害与炸弹伤害区分，绿色生命区与红色损失区正确。
- [ ] 炸弹仅触发一次并消失，爆炸位置正确。
- [ ] 移动球体在设置范围内运动，接触伤害有合理间隔。
- [ ] 血量归零重生，掉落重生，返回位置与当前检查点一致。
- [ ] 重生时不重复启动流程，完成后速度和控制恢复。
- [ ] 终点绿色旗触发通关，暂停、继续、重开和返回菜单可用。

## 重点组合用例

| 场景 | 观察重点 |
| --- | --- |
| 贴近敌人连续攻击 | 出生保护是否跳过敌人、是否重复结算 |
| 炸弹与敌人重叠 | 单次触发、伤害顺序、重生状态锁 |
| 重生过程暂停再恢复 | 计时是否卡住、控制能否恢复 |
| 检查点提示出现时掉落 | 提示与重生流程是否互相影响 |
| 连续三次重开 | 生命、镜头、分数、监听和音效是否残留 |

## 记录方式

记录浏览器版本、窗口大小、构建提交号、复现步骤、预期结果、实际结果和控制台日志。性能测试固定设备与路线，记录帧时间和内存，不仅凭肉眼判断“更流畅”。
